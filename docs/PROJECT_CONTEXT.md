# 실제 프로젝트 문맥

상태: **미연결 / starter**. 제품의 스택·도메인·배포 구조를 아직 가정하지 않는다.

| 항목 | 실제 확인 내용 | 근거 파일/명령 |
|---|---|---|
| 서비스 목표·사용자 | 미확인 | 도입 시 작성 |
| 저장소 구조·실행 환경 | 이 킷 자체는 Python 3.10+ 표준 라이브러리; 제품 환경은 미확인 | scripts/, tests/ |
| 프론트엔드 | 미확인 | 소스/lockfile 확인 |
| 백엔드·DB·인증 | 미확인 | 소스/배포 설정 확인 |
| AI·검색·RAG·도구 | 미확인 | 구현/필요성 확인 |
| 기능/계약/회귀 테스트 | 제품 연결 전 | 명령 실행 확인 |
| 모델·프롬프트·검색 버전 | 미확인 | 런타임/관리 정책 확인 |
| 규정·민감정보·로그 보존 | 미확인 | 책임자 확인 |
| 배포·롤백·권한 소유자 | 미확인 | 운영 문서 확인 |

## 결정 기록
새로운 아키텍처 선택은 이 표의 사실과 구분하여 ADR에 남긴다. 본 파일에 비밀값을 적지 않는다.

키트 제작 당시의 검증 기록은 `docs/VALIDATION.md`에서 이 프로젝트 문맥과 구분한다.
