# 실제 적용 사례 — 작성 전

## 문제와 책임 범위
제품/사용자 문제, 본인 기여와 타인의 기여, 적용 기간, 기존 코드 상태.

## 설계 판단
대안, 선택 근거, 제외한 범위, 비용/복잡도/안전성 trade-off.

## 구현 증거
Spec / 설계 / 작업 / PR / 관련 코드 / 실제 실행 로그의 링크.

## 개발 하네스
어떤 반복 작업을 자동화했고 무엇을 CI/권한으로 강제했는가? 문서 지침만 있는 부분은 무엇인가?

## 서비스 AI 평가
데이터 출처·표본/반복 수·holdout·모델/프롬프트/검색/도구 버전·평가기 검수.

## 전후 비교
같은 조건의 baseline/candidate, slice별 실패, 지연·비용, 개선되지 않은 부분과 한계.

## 검증 상태
구현 완료 / 자체 시험 / 실제 CLI / 실제 서비스 / 운영 검증을 별도로 표시한다.
